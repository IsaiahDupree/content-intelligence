## Key Integration Points

### Content Brief Pipeline
```
INPUT: { topic, platform, geo_optimize?, geo_location? }

STEP 1 (Parallel): AIL semantic query → fetch topic context
  Timeout: 600ms | Fallback: empty context

STEP 2 (Parallel): TikTok analytics → fetch platform+niche performance
  Timeout: 300ms | Fallback: empty performance data

STEP 3 (Parallel): Media Vault → search B-roll for topic
  Timeout: 500ms | Fallback: empty B-roll suggestions

STEP 4 (Sequential): GPT-4o brief generation
  Uses: context + performance + B-roll suggestions
  Output: Full ContentBrief JSON with hook, script, captions, etc.

STEP 5 (Optional): GEO optimization (if geo_optimize=true)
  Calls: tiktok-geo /api/geo/generate-brief
  Non-blocking: failure doesn't fail pipeline

OUTPUT: { brief_id, content_brief, geoOptimized?, error? }
```

### Performance Sync Pipeline
```
INPUT: (runs on schedule or manual trigger)

STEP 1 (Parallel): Media Vault performance checkback
STEP 2 (Parallel): TikTok analytics batch check

FOR EACH item with tier change:
  - Call AIL /api/ingest/social to re-embed updated data
  - Create cios_insight_log entry (type=viral_pattern|tier_upgrade)
  - Broadcast PERFORMANCE_UPDATED event via Realtime

OUTPUT: { items_synced, tier_changes, insights_generated }
```

### Event Bus (Supabase Realtime)

**Channel**: cios-events

**Events Published**:
- PIPELINE_STARTED: { pipeline_type, run_id, started_at }
- PIPELINE_STEP_COMPLETED: { run_id, step_name, duration_ms }
- PIPELINE_COMPLETED: { run_id, status, total_duration_ms, output? }
- PERFORMANCE_UPDATED: { post_ids, tier_changes, insights_created }
- INSIGHT_GENERATED: { insight_id, type, priority, content }
- BRIEF_CREATED: { brief_id, platform, topic, status }
